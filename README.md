# HMM-learning
Implementations of various Markov Chain, Hidden Markov model, signal processing etc. 

```markov_lab``` - testing convergence to the stationary distribution via simulation steps and repeated powers.
```hmm_problems``` - implementations of the Forwards algorithm and Viterbi for Hidden Markov Models.
```covariance_lab``` - scatter plots of multivariate normal simulations, moving the off-diagonal from positive to negative.
